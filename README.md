# Wall Finishing Simulator

Интерактивный 3D-симулятор отделочных и ремонтных работ на **Unity (2022.3 LTS)**. Проект включает процедурную генерацию геометрии помещения по точкам контакта, динамическое наслоение строительных материалов в реальном времени, валидацию технологических этапов, расчёт адгезии и систему высыхания слоёв.

## Ключевые особенности и реализованные системы

* **Процедурная генерация и обновление 3D-мешей (`WallMeshBuilder`, `WallGeometryService`):**
  * Генерация геометрии стен, полов и потолков в рантайме с динамическим перестроением мешей при изменении высоты или нанесении новых отделочных слоёв.
  * Автоматическое смещение и бесшовная стыковка соседних поверхностей по общим границам при изменении текущей геометрии.
* **Сборка комнаты по точкам контакта (`RoomBuilder`, `RoomManager`):**
  * Алгоритм автоматического построения замкнутого пространства комнаты на основе точек сопряжения поверхностей и корректная очистка ресурсов при удалении/пересоздании объектов.
* **Система многослойной отделки и технологических правил (`WallLayerService`, `AppliedLayerLogic`, `LayerOrderValidator`):**
  * Добавление, изменение и удаление слоёв (грунтовка, шпаклёвка, финишные покрытия) с проверкой технологической последовательности нанесения.
  * Расчёт коэффициента **адгезии** (`WallAdhesionCalculator`) и учёт **времени высыхания** (`DryingTimer`) для разных типов поверхностей и материалов.
* **Событийно-ориентированный UI (uGUI + MVC):**
  * Интерфейс построен по паттерну Model-View-Controller (`SurfaceSystem.UI.*`) и связан с игровой логикой через шину событий (`SurfaceEvents`).
  * Отображение прогресса отделки, фильтрация материалов, управление высотой слоя, таймер высыхания и система уведомлений об ошибках технологии.
* **Адаптивная аудиосистема (`SoundManager`) и орбитальная камера (`OrbitCameraController`):**
  * Звуковое сопровождение действий пользователя и этапов ремонта, а также плавное орбитальное управление камерой с защитой от перекрытия элементами UI.

## Архитектура проекта

Весь основной код изолирован в модульной структуре неймспейсов `SurfaceSystem`:

```text
Assets/Scripts/SurfaceSystem/
├── Camera/         # Орбитальный контроллер камеры (OrbitCameraController)
├── Components/     # Контроллеры поверхностей (стены, пол, потолок), логика нанесённых слоёв и подсветка
├── Core/           # Ядро системы: генератор комнаты (RoomBuilder), менеджер сцены, рейкаст-детектор и звук
├── Data/           # ScriptableObject-конфигурации материалов, типов поверхностей и геометрических данных
├── Events/         # Событийная модель взаимодействия между логикой и UI (SurfaceEvents)
├── Service/        # Сервисы расчёта геометрии и управления слоями поверхностей
├── UI/             # MVC-модули интерфейса (DryingTimer, MaterialFilter, SurfaceHeight, Notification и др.)
└── Utils/          # Вспомогательные алгоритмы: генерация мешей, валидатор порядка слоёв, расчёт адгезии
```

## Управление

* **ЛКМ по поверхности** — выбрать стену, пол или потолок для отделки.
* **ПКМ + перемещение мыши** — вращение камеры вокруг комнаты.
* **Колёсико мыши** — приближение и отдаление.
* **Панель UI** — выбор типа поверхности, настройка высоты слоя, фильтрация и нанесение материалов.
